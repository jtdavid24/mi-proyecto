# Análisis de Vehículos en Venta - Aplicación Web

Esta aplicación web, desarrollada con Streamlit, permite realizar un análisis exploratorio interactivo sobre un conjunto de datos de vehículos en venta en Estados Unidos.

## ¿Para qué sirve?

La aplicación permite a los usuarios explorar datos como:
- La distribución de precios de los vehículos disponibles.
- La relación entre el año del modelo y el precio.
- Obtener visualizaciones dinámicas con solo hacer clic en botones.

Esta herramienta está orientada a facilitar la comprensión de las tendencias del mercado de vehículos usados.

## Tecnologías utilizadas

- Python
- Streamlit
- pandas
- plotly-express
